# BrotherFastPrint

[![Android CI](https://github.com/sergeyviktorovich87/BrotherFastPrint/actions/workflows/build.yml/badge.svg)](https://github.com/sergeyviktorovich87/BrotherFastPrint/actions/workflows/build.yml)

[![License: GPL v3+](https://img.shields.io/badge/License-GPLv3%2B-blue.svg)](LICENSE)

Системная служба печати Android для **Brother HL-L2340DWR / HL-L2340DW series**. Подготавливает документ целиком на телефоне и передаёт его принтеру одним потоком через локальную сеть. Печать работает без компьютера, CUPS-сервера и интернета.

**[Скачать APK 0.3.2 Preview →](https://github.com/sergeyviktorovich87/BrotherFastPrint/releases/tag/v0.3.2-preview)**

Работа плагина и быстрая многостраничная печать подтверждены владельцем на Samsung Galaxy Z Fold6 (Android 16) и Brother HL-L2340DWR. Количественное сравнение пауз с другими драйверами пока не проводилось. Проект независимый; это не официальный продукт Brother.

## Установка

1. Скачайте `BrotherFastPrint-0.3.2-preview-arm64.apk` из релиза и установите на Android 8.0 или новее с процессором ARM64.
2. Подключите телефон и принтер к одной локальной сети. Откройте **BrotherFastPrint Preview**, нажмите **«Поиск»** и выберите принтер. IP и проверенный RAW-порт сохранятся автоматически. Адрес можно ввести вручную: по умолчанию `192.168.1.41:9100`.
3. Нажмите **«Настройки печати Android»** и включите **BrotherFastPrint Preview**. На Samsung этот раздел также находится в **Настройки → Подключения → Другие настройки подключения → Печать**; название пути зависит от прошивки.
4. В Word, просмотрщике PDF или другом приложении откройте **«Печать»** и выберите **Brother HL-L2340DWR · FastPrint**.

После включения службы держать экран приложения открытым не требуется. Приложение-источник должно поддерживать стандартную печать Android. Для PDF без такого меню есть **⋮ → Печать PDF напрямую**.

В тестовой **0.3.4 Preview** активный сеанс дополнительно поддерживается временной foreground-службой и ограниченным wake lock. Она завершается после отключения системного сеанса и окончания заданий; новых runtime-запросов разрешений нет. Это изменение ещё требует проверки на Samsung. [Обоснование и порядок теста](docs/BACKGROUND_0.3.4_RU.md).

Релиз обновляет ранее установленные **0.3.0/0.3.1 Preview** с сохранением настроек. Для старой 0.2.x используется другой пакет: две службы могут находиться на телефоне одновременно; отключите старую службу, чтобы не перепутать принтеры.

## Возможности

- Печать через стандартное меню Android и напрямую из PDF.
- A4, 600 DPI, чёрно-белая печать; ориентация и диапазон страниц.
- Односторонняя печать, duplex по длинному или короткому краю, копии с разбором по экземплярам и экономия тонера.
- Поиск поддерживаемого принтера через mDNS/DNS-SD, проверка соединения и ручной IP/порт.
- Работа через системный маршрут при VPN с разрешённым доступом к локальной сети; запасной физический маршрут используется только до передачи печатных данных.
- Отмена задания, прогресс подготовки и техническая диагностика с экспортом TXT по действию пользователя.
- Светлая и тёмная тема, интерфейс для обычных и складных экранов.

В тестовой **[0.3.3 Preview](https://github.com/sergeyviktorovich87/BrotherFastPrint/releases/tag/v0.3.3-preview)** добавлен режим **«Обработка изображения → Фото · улучшенные полутона»**: печатный растр 45° / около 106 lpi и коррекция плотности. По умолчанию остаётся прежний режим «Документы». Профиль применяется и в системной печати после закрытия экрана приложения. Физический результат нового режима ещё требует проверки; [подробности и порядок сравнения](docs/PHOTO_0.3.3_RU.md), [фактически выполненные проверки](docs/VALIDATION_0.3.3_RU.md).

В системном диалоге выбор duplex имеет приоритет над значением по умолчанию в приложении. Отображение дополнительных параметров зависит от системного интерфейса печати.

## Почему страницы печатаются быстрее

Android передаёт службе PDF. `PdfRenderer` в изолированном процессе обрабатывает его полосами; JNI-код превращает монохромный растр в Brother HBP с помощью минимальной части **[brlaser](https://github.com/pdewacht/brlaser)**. Весь результат сначала сохраняется во внутренний временный файл (**preload**), затем отправляется в **одном TCP-соединении на всё задание**.

Во время передачи следующая страница уже подготовлена. Принтеру не приходится ждать рендеринга каждого следующего листа. Полноразмерный ARGB Bitmap страницы и полный CUPS в APK не используются. Потоковый режим с одновременным рендерингом и отправкой пока не реализован: текущий режим выбран для непрерывной передачи готового задания.

## Совместимость и ограничения

| Параметр | Текущая версия |
| --- | --- |
| Проверенный принтер | Brother HL-L2340DWR; профиль HL-L2340D series |
| Проверенный телефон | Samsung SM-F956B, Android 16 / API 36 |
| Минимальная система | Android 8.0 / API 26 |
| Архитектура APK | `arm64-v8a` |
| Бумага / разрешение | A4 / 600 DPI / монохром |
| Транспорт | RAW TCP, обычно порт 9100 |
| Подготовка | Весь документ в приватном временном файле |
| Ограничения | PDF до 256 MiB, HBP до 512 MiB, до 500 выходных сторон с учётом копий и пустых оборотов |

Другие модели Brother не объявляются совместимыми только потому, что они есть в upstream brlaser. Short-edge, landscape duplex и физическая печать 50 страниц остаются отдельными аппаратными проверками. Результат TCP означает передачу байтов, а не подтверждение выхода бумаги. Нет достоверного определения «нет бумаги» или окончания физической печати по одному RAW TCP.

Если mDNS заблокирован маршрутизатором или VPN, используйте ручной адрес. Строгий VPN lockdown может запрещать оба маршрута. После **«Принудительно остановить»** Android может потребовать повторного открытия приложения. Обычное закрытие экрана приложения не должно препятствовать работе службы.

## Конфиденциальность

Документы обрабатываются на телефоне и передаются только выбранному принтеру. Нет облачной обработки, аналитики, сторонних API или входящего сервера. Временные документы хранятся во внутреннем каталоге приложения и удаляются после попытки печати; предусмотрена очистка после сбоя. После неопределённой ошибки передачи задание автоматически не повторяется.

RAW TCP не шифрует данные: используйте доверенную локальную сеть. Логи не содержат содержимого, названий и URI документов, но включают технические сведения, в том числе локальные IP. Перед публикацией лога проверьте его. Подробнее: [конфиденциальность](PRIVACY.md) и [безопасность](SECURITY.md).

## Сборка из исходников

Нужны JDK 17, Python 3, C++17-компилятор для host-тестов и Android SDK. Версии инструментов закреплены в проекте: Gradle 8.11.1, AGP 8.10.1, Kotlin 2.1.21, SDK 36, Build Tools 35.0.0, NDK 28.2.13676358 и CMake 3.22.1.

```bash
git clone https://github.com/sergeyviktorovich87/BrotherFastPrint.git
cd BrotherFastPrint

# Примите лицензии SDK и установите необходимые компоненты.
sdkmanager --licenses
sdkmanager 'platforms;android-36' 'build-tools;35.0.0' \
  'ndk;28.2.13676358' 'cmake;3.22.1'

# Задайте ANDROID_HOME либо sdk.dir в локальном local.properties.
bash tools/test_native.sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest \
  :app:assembleDebugAndroidTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Для Windows используйте `gradlew.bat` и подходящую среду для host-тестов. Проект также открывается в Android Studio. Интернет нужен для первоначальной загрузки инструментов и зависимостей сборки; для работы установленного приложения он не нужен.

**APK из CI и самостоятельной debug-сборки подписывается другим ключом** и не является обновлением проверенного Preview APK. Для разработки используйте отдельное устройство/профиль либо предварительно удалите установленную Preview, потеряв её настройки. Приватный ключ проверенного APK в репозиторий не входит. Версии инструментов закреплены, но побайтовое совпадение APK разных сборочных сред не обещается.

GitHub Actions запускает host-тесты, сборку, JVM-тесты и Android Lint. Android instrumented-тесты компилируются; автоматического запуска на устройстве в CI нет. Тесты не отправляют задания физическому принтеру.
