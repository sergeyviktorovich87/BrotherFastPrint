# Конфиденциальность

BrotherFastPrint обрабатывает задания локально. PDF поступает через Android Print Framework либо системный выбор файла; пользовательские документы, имена файлов и URI не отправляются разработчику. Обработанный поток HBP отправляется на выбранный адрес принтера. RAW TCP не шифруется.

Нет аналитики, рекламы, облачного рендера, сторонних API, входящего TCP/HTTP-сервера или автоматической отправки отчётов. Приложение не запрашивает доступ ко всем файлам, контакты, местоположение, камеру или микрофон.

Обычные разрешения Android:

| Разрешение | Назначение |
| --- | --- |
| `INTERNET` | TCP-соединение с локальным принтером; Android использует это разрешение и для локальных сокетов |
| `ACCESS_NETWORK_STATE` | Выбор маршрута и отслеживание доступности сети |
| `CHANGE_NETWORK_STATE` | Привязка сокета к разрешённой физической сети |
| `CHANGE_WIFI_MULTICAST_STATE` | Ограниченный по времени mDNS-поиск на старых Android |
| `FOREGROUND_SERVICE` | Временная служба поддержки активного сеанса печати |
| `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Тип этой службы для работы с сетевым принтером на Android 14+ |
| `WAKE_LOCK` | Ограниченный таймером частичный wake lock во время активной печати; освобождается после сеанса/заданий |

Начиная с тестовой 0.3.4 временная foreground-служба действует, пока Android подключён к PrintService либо имеются задания приложения. Она не запускается при загрузке телефона и не перезапускает задания после сбоя. Частичный wake lock получает timeout 60 секунд и обновляется через 20 секунд только при живом владельце; при завершении службы освобождается. Runtime-разрешение уведомлений не запрашивается: на Android 13+ отображение foreground-службы в панели уведомлений зависит от разрешений ОС, а сведения об активных foreground-службах доступны через системный интерфейс.

Временные PDF, монохромный растр и HBP хранятся во внутреннем каталоге приложения. После завершения попытки они удаляются; при следующем запуске удаляются оставшиеся spool-файлы. Это обычное удаление файлов, а не гарантия физического стирания флеш-памяти. Резервное копирование данных приложения отключено.

Диагностика содержит версию приложения, модель телефона, API Android, локальные адреса/порт, время, технические события и ограниченные сведения о собственных ошибках/завершениях процесса. Содержимое, названия и URI документов в журнал не записываются. Журнал ограничен и ротируется; это не архив документов.

TXT создаётся только при явном экспорте пользователем. Экспортированный файл и копия в буфере обмена находятся вне контроля внутренней очистки приложения. Перед размещением отчёта в публичном issue удалите сведения о своей сети, которые не хотите раскрывать.
