# Безопасность

Поддерживаемая опубликованная версия — **0.3.2-preview**. Используйте APK из Releases этого репозитория и проверяйте SHA-256. Отдельные CI-артефакты предназначены для разработки и используют другую debug-подпись.

Не размещайте в публичных issues документы, пароли, ключи подписи или конфиденциальные логи. Если на вкладке Security доступна кнопка **Report a vulnerability**, используйте её для закрытого сообщения. Иначе создайте issue только с кратким описанием класса проблемы без exploit, секретов и пользовательских данных, чтобы согласовать закрытый способ передачи деталей.

Приложение не открывает входящие порты. PrintService защищена системным разрешением `BIND_PRINT_SERVICE`; PDF обрабатывается в изолированном процессе. RAW TCP не обеспечивает шифрование и аутентификацию принтера: печатайте только в доверенной сети и проверяйте сохранённый адрес.

Нет гарантированного срока ответа или поддержки всех моделей Brother. Preview не следует считать прошедшей независимый аудит безопасности.
