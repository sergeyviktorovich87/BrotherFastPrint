BrotherFastPrint — локальная системная служба печати Android для Brother HL-L2340DWR.

Владелец подтвердил работу плагина на Samsung Galaxy Z Fold6 / Android 16: быстрая многостраничная печать, интеграция с системным меню и работа после исправления доступности принтера.

### Установка

1. Скачайте **BrotherFastPrint-0.3.2-preview-arm64.apk** ниже. Android 8.0+, ARM64.
2. Откройте приложение, найдите принтер кнопкой «Поиск» либо задайте IP/RAW-порт вручную.
3. Включите **BrotherFastPrint Preview** в настройках печати Android. При печати из других приложений выбирайте **Brother HL-L2340DWR · FastPrint**.

Держать экран приложения открытым не требуется. APK обновляет Preview 0.3.0/0.3.1 с сохранением настроек. Старое приложение 0.2.x использует другой пакет.

### Возможности и исправления

- A4 / 600 DPI / монохром, копии, диапазон страниц, duplex по длинному/короткому краю и экономия тонера.
- Весь документ подготавливается до передачи и отправляется одним TCP-заданием; ПК и интернет не нужны.
- Поиск IP и RAW-порта, ручной адрес, поддержка разрешённого VPN-маршрута, локальная диагностика.
- В 0.3.2 исправлены начальная готовность принтера и обработка системной очереди без открытия Activity.
