# Проверки 0.3.3 Preview

Дата: 1 ноября 2026 года.

## Основание

Владелец предоставил снимок двух отпечатков: FastPrint воспроизводит тёмные участки фотографии плотнее стандартного сервиса. Проверен исходный код: рассредоточенный Bayer 8×8 без тоновой коррекции. Добавлен отдельный фото-профиль; подробное обоснование и ограничения — [PHOTO_0.3.3_RU.md](PHOTO_0.3.3_RU.md). Сам снимок не входит в репозиторий.

## Выполнено

- Host native-наборы, проверка upstream blob-хешей и независимое декодирование HBP 1/10/50 полных A4, duplex и пустых оборотов прошли.
- Новый native-набор проверяет все 256 яркостей, чёрный/белый, меньшую плотность полутонов, кластеризацию точек, сохранение теней/светов, фазу между полосами разной высоты, padded stride, trailing bits, прозрачность и неизвестный профиль.
- ASan/UBSan для нового фото-преобразования прошли. LeakSanitizer отключён (`ASAN_OPTIONS=detect_leaks=0`): в этом окружении он завершается ошибкой из-за ptrace; проверка утечек этим прогоном не заявляется.
- GitHub Actions run `41307840065`: `assembleDebug`, `testDebugUnitTest`, `assembleDebugAndroidTest`, `lintDebug` и native-проверки завершены успешно.
- JVM HTML-отчёт: **60 тестов, 0 failures, 0 ignored**. Четыре новых теста проверяют default/ID, сохранение плана duplex/copies, технические имена и отказ неизвестному профилю.
- **10 instrumented-тестов собраны, но не запускались.** Добавлен сквозной сценарий Photo через Binder/sandbox/JNI с проверкой HBP job framing и технических событий.
- CI artifact `13083873197` скачан через GitHub; его SHA-256 сверена с digest Actions до извлечения APK. Код приложения при подписании не менялся.

## Границы результата

На телефоне/принтере эта версия пока не проверена. Установка поверх 0.3.2 ожидается по совпадению package/сертификата и большему versionCode, но не выдаётся за выполненный device-тест. Численное совпадение со стандартным драйвером, физический dot gain, видимость деталей, отсутствие полос и влияние на межстраничные паузы требуют бумажного сравнения. Фото-профиль opt-in, прежний режим документов по умолчанию сохранён. Разница кадрирования ещё не диагностирована; матрица PaperGeometry не менялась.
