# Проверки 0.3.5 Preview

## Основание изменения

Baseline приложения 0.3.4 с новыми instrumented-тестами: source `4ca690e34a5ab239868519c4954852a15c11980b`, run [41359319489](https://github.com/sergeyviktorovich87/BrotherFastPrint/actions/runs/41359319489). Выполнены 14 тестов; воспроизведено исчезновение foreground-службы при поступлении нового владельца между stopService и onDestroy. Это ошибка 0.3.4, не доказательство причины прежнего пользовательского эпизода 0.3.3.

После явного startForegroundService для каждого нового владельца run [41360058824](https://github.com/sergeyviktorovich87/BrotherFastPrint/actions/runs/41360058824) выполнил все три теста службы успешно. Единственным оставшимся сбоем было прежнее требование полного побитового совпадения сглаженного PDF: 101/126300 пикселей различались на одну единицу RGB. Производственный рендер не менялся. Для текста установлена ограниченная погрешность округления и добавлен отдельный точный тест чёрно-белой геометрии; [обоснование](BACKGROUND_0.3.5_RU.md).

## Границы проверки

Emulator-тест запускает foreground-службу из открытой тестовой Activity и затем закрывает экран. Он не воспроизводит прошивку Samsung и холодный системный binding. Установка обновления, работа без открытия приложения на SM-F956B, фото-профиль на бумаге, short-edge/landscape duplex и физические 50 страниц остаются аппаратными проверками. Неопределённые задания автоматически не повторяются. Нативная обработка фото в этой версии не изменялась.

Подтверждённые результаты исходных владельческих испытаний 0.3.2 не переносятся автоматически на новые сценарии 0.3.5. Подробный порядок проверки на телефоне находится в [BACKGROUND_0.3.5_RU.md](BACKGROUND_0.3.5_RU.md).
